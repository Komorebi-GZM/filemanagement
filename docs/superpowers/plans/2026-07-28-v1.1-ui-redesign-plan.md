# V1.1 UI Redesign and Command Palette Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the V1.1 redesign which introduces a global Command Palette (Ctrl+K) for tagging/searching, modernizes the left sidebar with dynamic counts, adds a gallery view, and refactors the right inspector panel for in-place editing.

**Architecture:** We will build a new `CommandPalette` widget in `src/app/ui/` and update `MainViewModel` to handle fuzzy matching and dynamic counting. The left sidebar will drop `QTreeWidget` in favor of a `QListWidget` for smart views. The right sidebar will unify tabs into a scrollable `QScrollArea`. Tests will use `pytest` and `pytest-qt` for UI validation.

**Tech Stack:** Python 3.11, PyQt5, SQLite, pytest, pytest-qt

## Global Constraints

- 必须使用本地现有的 `py311-pack` Conda 环境进行开发与运行（Python 3.11）。
- 搜索输入延迟需低于 50ms。
- 数据库表结构完全向下兼容 V1.0。

```python
from PyQt5.QtWidgets import QWidget, QVBoxLayout, QLineEdit, QListWidget
from PyQt5.QtCore import pyqtSignal

class CommandPalette(QWidget):
    text_entered = pyqtSignal(str)

    def __init__(self, parent=None):
        super().__init__(parent)
        layout = QVBoxLayout(self)
        self.search_box = QLineEdit()
        self.list_widget = QListWidget()
        layout.addWidget(self.search_box)
        layout.addWidget(self.list_widget)
```

```python
# In src/app/viewmodel/main_viewmodel.py add:
    def fuzzy_search_tags(self, query: str):
        all_tags = self.db.get_all_tags()
        if not query:
            return all_tags
        return [t for t in all_tags if query.lower() in t.tag_name.lower()]
```

```python
from PyQt5.QtWidgets import QShortcut
from PyQt5.QtGui import QKeySequence

# In MainWindow.__init__:
        self.command_palette = CommandPalette(self)
        self.command_palette.hide()

        self.shortcut_k = QShortcut(QKeySequence("Ctrl+K"), self)
        self.shortcut_k.activated.connect(self.toggle_command_palette)

# In MainWindow class:
    def toggle_command_palette(self):
        if self.command_palette.isHidden():
            self.command_palette.show()
            self.command_palette.search_box.setFocus()
        else:
            self.command_palette.hide()
```
